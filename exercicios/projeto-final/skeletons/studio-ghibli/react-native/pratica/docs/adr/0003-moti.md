# ADR 0003 — Moti para animações

- **Status:** aceito
- **Data:** 2026-11-07

## Contexto
Queremos pequenas animações que deem resposta ao usuário, como a estrela crescendo ao favoritar e a entrada suave da tela de detalhe. Também queremos *Skeleton loading* no carregamento: blocos cinza no formato do conteúdo, que aparecem enquanto os dados não chegam. A Aula 5 recomenda essa técnica no lugar de um ícone de carregamento isolado.

Uma biblioteca conhecida para isso é o Motion (antigo Framer Motion), mas ela é feita para sites e não funciona nas telas nativas do React Native.

## Decisão
Usar **Moti**. Com ele, basta dizer como o elemento começa e como termina, e a biblioteca cuida do movimento. O Moti funciona por cima do **Reanimated**, a biblioteca de animação que já veio instalada no projeto. O Skeleton loading usará o componente pronto `moti/skeleton`.

## Alternativas descartadas

### Reanimated direto, sem o Moti
Como o Moti funciona por cima do Reanimated, poderíamos usar apenas o Reanimated.

**Por que não:** ele dá mais controle, mas pede bem mais código até para uma animação simples, como um elemento que aparece aos poucos. Nossas animações são curtas, então o Moti resolve com menos trabalho. Se surgir um caso em que o Moti não for a melhor opção, usaremos o Reanimated só nesse ponto. É o caso da entrada do símbolo do Kodama, uma sequência de vários passos com tempos exatos, em `src/components/kodama-mark.tsx`. O efeito de pressionar o card também usa o Reanimated direto, porque os tipos do `MotiView` não são compatíveis com o Reanimated 4 no TypeScript.

### `Animated`, que já vem no React Native
Não exigiria instalar nada além do que o React Native já traz.

**Por que não:** é mais limitado. Um celular usa uma linha de execução para desenhar a tela e outra para rodar o nosso código. Quando a animação depende da linha do nosso código e ela está ocupada, o movimento engasga. O `Animated` só consegue evitar isso em parte dos casos (mexer em posição, tamanho visual e transparência), enquanto o Reanimated, usado pelo Moti, foi feito para rodar as animações na linha que desenha a tela. O código do `Animated` também é mais longo.

### Lottie
Reproduz animações prontas, criadas por designers em programas como o After Effects.

**Por que não:** serve bem para ilustrações animadas, como um personagem se mexendo. Nossas animações, porém, reagem ao que acontece no app: o filme virou favorito, o botão foi pressionado. Além disso, não temos um designer de animação nem arquivos prontos para reproduzir.

## Consequências
- ✅ Animações curtas, escritas com pouco código e fluidas mesmo quando o app está ocupado.
- ⚠️ Algumas pessoas ativam "reduzir movimento" no celular porque animações causam desconforto. O app precisa respeitar essa opção, usando o recurso `useReducedMotion`.
